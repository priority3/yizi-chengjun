# 字斗西游

西游题材的文字合成塔防 H5 小游戏，上下分屏对战 AI「六耳猕猴」。纯 Canvas 2D 绘制，运行时零依赖。

## 运行

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm dev:host     # 手机和电脑连同一个 WiFi，用手机打开终端里显示的 Network 地址
pnpm test         # 单测 + 无头对局测试
pnpm sim [局数]   # 打印各关 AI 胜率表，调数值用（默认每组 60 局）
pnpm build        # 类型检查 + 打包到 dist/，可部署到任意静态服务器
```

## 玩法

- 点「化缘」花功德抽字，字落在随机空格里；每化缘一次涨价。
- 同字同级拖到一起升 1 级（最高 5 级）；拖到空格是移动，拖到别的字上是交换；拖到化缘按钮上是卖出。
- 名字碎片（悟/空、八/戒、沙/僧、白/龙）拖到另一半上觉醒英雄；「神」拖到兵字或英雄上变成神X。
- 妖怪同时进攻两边，走到头扣唐僧的心；对方的心先扣光你就赢。10 波后进入加时，妖怪越来越强。

## 代码结构

| 目录 | 内容 |
|---|---|
| `src/config/` | 数值表：字、组合、妖怪、关卡与 AI 难度。调平衡只改这里 |
| `src/core/` | 纯逻辑，固定步长 1/60 秒，带种子随机数，同种子可完全重放 |
| `src/render/` | 布局、绘制、特效（只读逻辑状态） |
| `src/ui/` | 输入、HUD、各场景 |
| `src/platform/web.ts` | 画布适配、移动端手势屏蔽、存档 |

改数值后跑 `pnpm sim` 看胜率表。当前目标：第 1 关人类代理胜率约 85%，逐关下降到第 5 关约 35%。
