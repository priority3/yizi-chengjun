# 字斗西游

西游题材的文字合成塔防 H5 小游戏。屏幕中间是一块阵地，妖怪从上下两座城门往阵地打。每波打完开商店，把书法字卡拖上阵地：同字合成升级，凑齐名字觉醒英雄。纯 Canvas 2D 绘制，运行时零依赖，美术全部由代码画出。

## 运行

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm dev:host     # 手机和电脑连同一个 WiFi，用手机打开终端里显示的 Network 地址
pnpm test         # 单测 + 机器人闯关测试
pnpm sim [局数]   # 机器人打每一章的胜率表，调数值用（默认每章 40 局）
pnpm build        # 类型检查 + 打包到 dist/，可部署到任意静态服务器
pnpm font <ttf>   # 新增中文文字后，重新裁剪书法字体子集
```

## 玩法

- **构筑期**：商店有 3 张卡，拖到阵地空格上就是买下；拖到同名同级的卡上，买下后直接合成升级。刷新商店要花功德，价格递增；点「出战」开打下一波。
- **阵地**：开局开放中间两行，上下两行点「+」花功德解锁。场上的字随时可以拖动，用来移动、交换、合成、觉醒英雄和附神；拖进垃圾桶可以卖掉，返还一半。
- **字卡**：
  - 兵字：棍（近战）、箭（远程）、火（溅射）、冰（减速）、雷（天雷重击）
  - 辅助：速（周围加攻速）、钱（产功德）、疗（阵地回血）
  - 名字碎片：悟/空、八/戒、沙/僧、白/龙，两半合在一起觉醒英雄：
    - 悟空：金箍棒贯穿一排
    - 八戒：砸地群晕
    - 沙僧：月牙铲斩杀残血
    - 白龙：横扫全场
  - 「神」：拖到兵字或英雄上，变成神X
- **章节**：10 章，每章 5～8 波，中段有精英魔将，最后是章节 Boss。Boss 各有特性：复活、冲刺、召唤、免疫减速、护甲、回血、分裂。阵地血量归零就失败；通关解锁下一章。

## 代码结构

| 目录 | 内容 |
|---|---|
| `src/config/` | 数值表：字卡、组合、妖怪、章节与经济。调平衡只改这里 |
| `src/core/` | 纯逻辑，固定步长 1/60 秒，带种子随机数，同种子可完全重放；`bot.ts` 是给模拟用的机器人 |
| `src/render/` | 画面：自适应布局、战场背景、字卡、英雄头像、妖怪、特效、HUD 和商店面板 |
| `src/ui/` | 输入、各场景（标题、选章、对局） |
| `src/platform/web.ts` | 画布适配、移动端手势屏蔽、存档 |

改完数值后跑 `pnpm sim` 看胜率表。当前机器人的胜率从第 1 章约 93% 逐章降到第 10 章约 10%；真人会摆位、会凑合成，一般比机器人打得好。

## 字体

书法字用的是马善政楷书（Ma Shan Zheng），SIL Open Font License 1.1，协议见 `public/fonts/OFL.txt`。仓库里只放按游戏用字裁剪出来的子集 `zdxy-brush.woff2`。
