# 字斗西游

西游题材的文字合成塔防 H5 小游戏，玩法像《王国保卫战》：每章一张手绘地图，妖怪沿着路从城门走向唐僧的营地，路边有一个个石台，把书法字卡拖到石台上就是一座塔。同字合成升级，凑齐名字觉醒英雄；英雄攒满怒气放大招，波间奇遇三选一，通关拿灵石炼法宝。地图比屏幕大，可以拖动和缩放。纯 Canvas 2D 绘制，运行时零依赖，美术全部由代码画出。

## 运行

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm dev:host     # 手机和电脑连同一个 WiFi，用手机打开终端里显示的 Network 地址
pnpm test         # 单测 + 机器人闯关测试
pnpm sim [局数] [法宝,法宝:阶]   # 机器人打每一章的胜率表，调数值用（默认每章 40 局、不带法宝）
pnpm build        # 类型检查 + 打包到 dist/，可部署到任意静态服务器
pnpm font <ttf>   # 新增中文文字后，重新裁剪书法字体子集
```

## 玩法

- **构筑期**：商店有 3 张卡，拖到路边的石台上就是买下；拖到同名同级的卡上，买下后直接合成升级（松开前会有金色转圈提示）。刷新商店要花功德，价格递增；点「出战」开打下一波。
- **地图与石台**：妖怪从城门沿路走到营地，走到了就按攻击力扣阵地血量，归零失败。一部分石台开局就能用，其余点一下花功德解锁。场上的字随时可以拖动，用来移动、交换、合成、觉醒英雄和附神；拖进垃圾桶可以卖掉，返还一半。
- **镜头**：按住空地拖动平移，双指或滚轮缩放。
- **字卡**：
  - 兵字：棍（近战）、箭（远程）、火（溅射）、冰（减速）、雷（天雷重击）
  - 辅助：速（周围加攻速）、钱（产功德）、疗（阵地回血）
  - 名字碎片：悟/空、八/戒、沙/僧、白/龙，两半合在一起觉醒英雄：
    - 悟空：金箍棒贯穿一排
    - 八戒：砸地群晕
    - 沙僧：月牙铲斩杀残血
    - 白龙：横扫全场
  - 「神」：拖到兵字或英雄上，变成神X
- **英雄大招**：英雄每次普攻攒 10% 怒气（神英雄更快），卡片下方有怒气条，攒满后卡片发光，下一击改放大招：
  - 悟空「金箍棒·横扫」：目标所在那条路上的妖怪全挨一棒并击退
  - 八戒「钉耙·天降」：钉耙从天而降，大范围伤害并长时间眩晕
  - 沙僧「宝杖·连斩」：连斩射程内血最少的五只，残血直接斩杀
  - 白龙「龙吟」：全场伤害、击退并减速
- **奇遇**：每清掉第 2、4、6 波，构筑期开始时三选一，选完才能继续买卡/出战：
  - 福缘（立刻生效）：观音赐福（阵地回满、上限 +10）、财神到（+50 功德）、天降神字（空格上落一张「神」）
  - 机缘：土地公摆摊（本轮商店半价、刷新免费）、宝箱（打完下一波开出一张随机卡）
  - 劫难（下一波生效，赏金翻倍）：妖风大作（妖怪更快）、月圆之夜（妖怪更厚）、狼群来袭（全是狼，数量 ×1.5）、盗宝妖（混进一只小偷，摸到阵地偷 30 功德）、妖王亲临（波尾来一只半血妖王）
- **法宝**：通关得灵石（首通更多），每章首通固定送一件法宝；选章页的「法宝」里可以花 30 灵石随机炼器，三件同名同阶合成高一阶（最高三阶），出战最多带三件。效果包括阵地血量、开局功德、每波回血、全体/单字伤害、射程、溅射范围、眩晕时长、斩杀线、怒气积攒、妖怪移速。
- **章节**：10 章 10 张地图，每章 5～8 波，中段有精英魔将，最后是章节 Boss。Boss 各有特性：复活、冲刺、召唤、免疫减速、护甲、回血、分裂。后面的章节有两三个入口。

## 自定义路线

地图写在 `src/config/maps.ts` 里，一章一张 ASCII 图，一个字符是一块 48×48 的地：

```
1-4  妖怪入口（每个数字一条路）    E  营地（所有路的终点，只能有一个）
#    路                           O  开局可用的石台    o  要花功德解锁的石台
~    水（火山图里是岩浆）  ^ 岩石   T  树             .  空地
```

路必须是从入口到营地的一条走廊（不要 2×2 的路块、不要交叉），拐角会自动变圆。改几行字符、跑一下 `pnpm test` 就能换路线；`hp` 字段是这张图的难度微调，路越长妖怪血量会自动越厚。

## 代码结构

| 目录 | 内容 |
|---|---|
| `src/config/` | 数值表：字卡、组合、妖怪、章节与经济、英雄大招、法宝；`maps.ts` 是十张 ASCII 地图 |
| `src/core/` | 纯逻辑，固定步长 1/60 秒，带种子随机数，同种子可完全重放；`map.ts` 把 ASCII 图变成路线和石台、`ultimates.ts` 大招、`encounters.ts` 奇遇、`treasures.ts` 法宝库；`bot.ts` 是给模拟用的机器人 |
| `src/render/` | 画面：自适应布局、镜头（`camera.ts`）、地图绘制（`map-art.ts`）、字卡与按等级变化的插画（`cards.ts`、`unit-art.ts`）、英雄头像、妖怪、特效与大招动画、HUD、商店、奇遇面板、法宝图标 |
| `src/ui/` | 输入、各场景（标题、选章、对局与结算、法宝页） |
| `src/platform/web.ts` | 画布适配、移动端手势屏蔽、存档（章节进度 + 法宝库，兼容旧存档） |

改完数值后跑 `pnpm sim` 看胜率表。当前不带法宝的机器人胜率从第 1 章约 98% 逐章降到第 10 章约 13%（`pnpm sim 40`：98/95/75/70/48/40/43/33/13/13）；带三件一阶法宝（`pnpm sim 60 金刚琢,照妖镜,定风珠`）各章再涨 5～20 个百分点。真人会摆位、会凑合成、会挑奇遇，一般比机器人打得好。

每章都从同样的小经济重新开始，而妖怪血量逐章上涨，所以后面的章节击杀和清波的功德收入会按章节递增（`INCOME_GROWTH`），否则后期根本攒不出伤害。
